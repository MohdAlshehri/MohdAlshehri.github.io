# موقع محمد الشهري الشخصي

الرابط: **https://mohdalshehri.github.io**
النسخة الإنجليزية: **https://mohdalshehri.github.io/en/**

الموقع ثابت (بدون قاعدة بيانات)، مبني بـ Astro، وينشر نفسه تلقائياً على GitHub Pages مع كل تعديل.

---

## كيف أعدّل المحتوى؟ (بدون برمجة)

كل النصوص في ملفين فقط داخل المجلد `src/data`:

| الملف | ماذا فيه |
|---|---|
| `src/data/site.js` | الاسم، المسمى، نص الواجهة، بيانات التواصل، المسيرة، الإنجازات، الشهادات، التوصيات، الأدوات |
| `src/data/projects.js` | كل المشاريع والمنتجات ودراسات الحالة |

كل نص مكتوب مرتين: `ar` للعربي و `en` للإنجليزي. عدّل الاثنين.

### التعديل من الجوال أو المتصفح
1. افتح المستودع في GitHub، ثم افتح الملف (مثلاً `src/data/projects.js`).
2. اضغط أيقونة القلم ✏️ (Edit).
3. عدّل النص بين علامتي التنصيص `" "` فقط، ولا تحذف الفواصل `,` أو الأقواس.
4. اضغط **Commit changes**.
5. بعد دقيقة إلى دقيقتين يتحدث الموقع تلقائياً. تقدر تتابع النشر من تبويب **Actions**.

### إضافة مشروع جديد
في `src/data/projects.js`:
1. انسخ كتلة مشروع كاملة من `{` إلى `},`.
2. الصقها تحت آخر مشروع.
3. غيّر `slug` لاسم إنجليزي فريد بدون مسافات (مثل `"new-system"`). هذا يصير رابط الصفحة.
4. `group: "work"` يظهر في «مشاريع مختارة»، و `group: "product"` في «منتجات رقمية وتجارب».
5. `mock` يحدد شكل المعاينة المرسومة. الخيارات المتاحة:
   `booking` حجوزات · `attendance` حضور · `portal` لوحة إحصاءات · `accreditation` اعتماد ·
   `files` ملفات · `report` تقرير يومي · `assistant` مساعد ذكي · `wathiq` منصة ·
   `library` مكتبة · `legal` عقود · `fund` صندوق · `excel` جداول
6. `before` هي النقاط المكتوبة بخط اليد في ورقة «قبل». أربع نقاط قصيرة تكفي.

### تغيير الصورة الشخصية
استبدل الملف `public/images/mohammed.webp` بصورة جديدة بنفس الاسم.

## ملاحظات خصوصية
- لا يُعرض رقم الهوية أو تاريخ الميلاد أو رقم ترخيص الهيئة.
- المعاينات كلها توضيحية ببيانات وهمية، ولا تحتوي أسماء أشخاص أو عملاء حقيقيين.

## للمطور (اختياري)
```bash
npm install
npm run dev     # معاينة محلية على http://localhost:4321
npm run build   # بناء الموقع في مجلد dist
```
